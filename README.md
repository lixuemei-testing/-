# 个人作品集展示页

这是一个现代化的个人作品集展示页，专为面试和展示用途设计。

## 特性

✨ **现代设计**
- 现代化的卡片式布局
- 渐变色背景和平滑过渡效果
- 响应式设计，支持各种设备

🎨 **交互效果**
- 平滑的页面滚动动画
- 悬停效果和过渡动画
- 数字计数器动画
- 页面加载时的淡入效果

📱 **响应式**
- 完全响应式设计
- 移动端友好
- 平板和桌面设备优化

🚀 **性能**
- 轻量级代码
- 快速加载
- 无外部依赖

## 如何使用

### 1. 本地预览

直接在浏览器中打开 `index.html` 文件即可预览效果。

### 2. 部署到GitHub Pages

```bash
# 1. 确保你已经将代码推送到GitHub仓库
# 2. 在仓库设置中启用GitHub Pages
# 3. 选择 main 分支作为源
# 4. 稍等几分钟后，你的页面将在以下地址可用:
# https://lixuemei-testing.github.io/repository-name
```

### 3. 自定义内容

编辑 `index.html` 文件，根据需要修改以下内容：

- **个人信息**：修改名字、职位和描述
- **关于部分**：更新你的个人介绍和统计数据
- **项目部分**：添加你的真实项目信息
- **技能部分**：列出你掌握的技能
- **联系方式**：更新邮件、GitHub 和 LinkedIn 链接

### 4. 自定义样式

编辑 `styles.css` 文件可以修改：

- 主题颜色（在 `:root` 中修改 CSS 变量）
- 字体和排版
- 间距和布局
- 动画效果

## 颜色主题

当前使用的颜色方案：

```css
--primary-color: #667eea      /* 主色 - 紫蓝色 */
--secondary-color: #764ba2    /* 辅助色 - 深紫色 */
```

### 更改主题颜色

在 `styles.css` 中修改 `:root` 部分的 CSS 变量即可快速改变整个页面的配色。
